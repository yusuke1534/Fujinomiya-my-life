富士宮マイライフ v1.0

公開方法：このフォルダ内のファイルをGitHubリポジトリのルートにアップロードし、Settings > Pages > Deploy from a branch > main / root を選択します。公開URLをiPhoneのSafariで開き、共有 > ホーム画面に追加を選択してください。

ローカルでの確認：python3 -m http.server 8000 で http://localhost:8000 を開きます。位置情報・サービスワーカーは原則HTTPSで動作します。

搭載：ホーム、12カテゴリ、OpenStreetMap施設検索（Nominatim）、保存、地図、経路案内、現在地、天気、メモ、予定、支出記録、単価比較、仕事計算、防災チェック、リンク登録、JSONバックアップ。

注意：公開Nominatimは小規模・低頻度の利用向けです。検索の網羅性・可用性は保証されません。多数の検索をする場合は適切な商用/専用APIへの切り替えが必要です。保存データは端末ごとに別です。施設の手入力登録には緯度経度がないため、地図ピンは表示されません。
